## 通用排除过滤（两列表都过一遍）

- `otokonoko` tag + 「男娘」标题 → 丢。
- 列表是动漫风（Koikatsu/MMD/Blender）时，VAM(Virt-A-Mate) 写实风作品即使带 silhouette/belly dance 标签也排除——风格不符。
- **幼态角色不排除**：loli/shota/child/ロリ/幼/JS 字样及明显幼态角色（驱逐舰娘、Liliya、Anchorage、木之本樱、Frieren 等）照常收——用户明确想看这类。

## 打分模板（两列表通用）

1. A 档 = 命中该列表定义性硬信号（silhouette→影子词/剪影tag；veil→egyptian/belly_dance/arabian/异域舞娘）。按 views 排。
2. B 档 = 用户点名作者 + 同题材（NTR/QOS）但没打硬标签的作品。按 views 排，标注"风格推断"。
3. 全量过「通用排除过滤」再报。
4. 交付分 A/B 两档 markdown，每条 = 标题、@作者、时长、views、直链；注明哪些是硬信号命中、哪些是推断。
